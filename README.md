# Yvonne Cleans

A responsive, single-page website for **Yvonne Cleans**, a residential and commercial cleaning service based in Pretoria.

**Live site:** <https://yvonne-cleans.vercel.app>

## Overview

The project presents Yvonne Cleans’ services, brand story, testimonials, gallery, and quotation journey in a mobile-first format. It is a static website built with HTML, CSS, and JavaScript.

## Highlights

- Residential, office, deep-cleaning, move-in/move-out, event, and upholstery-cleaning services.
- Responsive navigation and layouts for mobile, tablet, and desktop screens.
- Service cards, photo gallery, testimonials, FAQ accordion, and quote call-to-action.
- WhatsApp-oriented contact and quotation flow.
- Accessibility-minded interaction, including keyboard support and reduced-motion handling.
- SEO and Open Graph metadata.

## Project structure

```text
yvonne-cleans/
├── index.html          # Main website page
├── css/styles.css      # Responsive styling
├── js/main.js          # Menu, form, scroll, and animation behaviour
└── assets/images/      # Website imagery
```

## View locally

Clone the repository and open `yvonne-cleans/index.html` in a browser. No package installation or build step is required.
